# KSH Shell

Hello! My name is Kim and as of writing this shell I am in my penultimate year of my university studies. I wanted to write this shell to get better at C++ so most line of code is handwritten! 

For this project, I used CodeRabbit to review my code to make sure there weren't too many issues with code.

Blog which inspired this project: https://brennan.io/2015/01/16/write-a-shell-in-c/

# Installation 

Clone the repo

```text
git clone https://github.com/K1mmyn/kim-shell-cpp.git
```
Run the make file

```text
make
./main
```
